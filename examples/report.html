Call drop rate

Bars use the same scale: 5 pixels per percentage point. N/A means no established calls.

How it is calculated

Call drop % = 100 x dropped calls / established calls.
Setup success % = 100 x established calls / call attempts.
Throughput Mbps = 8 x total download MB / total transfer seconds (decimal MB).
Latency = arithmetic mean of interval latency measurements. Peak use = highest interval utilization.

Demo thresholds: call drop > 2%; latency > 50 ms; throughput < 10 Mbps; peak use > 85%.

Thresholds are learning examples, not operator SLAs. Alarms flag symptoms for investigation; they do not prove root cause or RF congestion.
